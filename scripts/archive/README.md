# Scripts Archive

This directory contains one-shot scripts and migrations that have been landed and are no longer actively maintained. These are preserved here for historical reference to understand how the codebase came to be in its current state.

## Status

- **Maintenance**: None. These scripts are not supported and should not be run against production without careful review.
- **Use case**: Historical record, reference implementations, and occasional manual operations by the project maintainer.

## When to use

Only use archived scripts if:
1. You fully understand the original context and why the migration was needed
2. You have manually verified the script is compatible with the current codebase schema
3. You are comfortable handling any errors that may occur — no support is available

## Contents

Each script is documented with comments explaining its purpose at the time it was created.
